Comparing versions
==================

Pick a pollutant and the versions to compare: the chart shows the index
(IAQI) for each concentration, one line per version, and the table lists the
concentration range of every band. Cells that differ from the previous
selected version are highlighted. Drag on the chart to zoom, double click to
reset. The curves and tables are computed from the library when the
documentation is built. Without JavaScript the tables of all the pollutants
are shown.
